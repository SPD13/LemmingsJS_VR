LEMMIX JS+VR — SETUP GitHub

An engine to run legacy Lemmings games and Lemmix engine and levels with 3D rendering and VR compatibility.
setup guide ▶ PLAY
The NeoLemmix engine and the levels are stored locally, in this browser. Nothing installed here goes to a server: it lives in this site's storage on this device, and it is wiped if you clear the browser's data for this site (each browser, and each address of the site, has its own copy). None of the copyrighted assets are shipped with this engine, you will need to bring your own versions.

NeoLemmix

The files come from neolemmix.com, which does not let a web page download them by itself: the first button saves the official zip through your browser, the second installs the zip you saved (or drop it on the row).

Levels

None of the copyrighted assets ship with this engine. You need to own the original game to use the Lemmings and Oh No! More Lemmings levels. The NeoLemmix levels are provided by their authors, and their licences apply. Check the licence of the levels with their respective authors.
A level zip or folder lands in its own directory (NeoLemmix packs, or a DOS game's files). Drop a zip anywhere on this section.
The Lemmings Plus packs come from neolemmix.com: the first button opens the official download there in a new tab, the second installs the zip your browser saved.
The original Lemmings levels come two ways: the NeoLemmix install above brings them as NeoLemmix packs, played by the Lemmix engine, and the button below installs the DOS game files, played by the classic DOS-like engine.
Lemmings and Oh No! More Lemmings come from github.com/oklemenz/LemmingsJS, the project this one forks: that button copies the game files straight from the repository, with no zip to save.
